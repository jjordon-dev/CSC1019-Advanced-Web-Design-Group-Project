# CSC1019 Advanced Web Design Group Project

## Personal Diary Blog Website

A group web design project developed for the CSC1019 Advanced Web Design module.

The project is a personal diary and blog-style website built using HTML, CSS, and JavaScript. It contains multiple themed pages and interactive elements demonstrating front-end web development, responsive design, navigation, and user interface design.

## Technologies Used

- HTML5
- CSS
- JavaScript

## Pages

The website includes:

- Home
- Space
- Music
- Blogs
- Sports
- Merch
- Products
- Cart
- Login
- Contact

## Features

- Multi-page website structure
- Responsive page layouts
- Navigation between different sections
- Blog-style content
- Product and merchandise pages
- Shopping cart interface
- Login page
- Contact page
- Interactive elements using JavaScript
- Custom styling using CSS
